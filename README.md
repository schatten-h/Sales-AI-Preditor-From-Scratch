# Sales Predictor

## Description

Machine learning project for predicting product sales and business success using regression and classification algorithms built from scratch in Python.

## Objectives

- Learn supervised machine learning
- Implement linear regression from scratch
- Implement logistic regression from scratch
- Practice preprocessing and feature engineering
- Build an interactive Streamlit application

## Technologies

- Python
- NumPy
- Pandas
- Streamlit

## Features

- Synthetic sales dataset generation
- Data preprocessing
- Feature normalization
- Linear regression
- Logistic regression
- Interactive prediction interface
